# SiK Corpse Loot Guard

Mod diagnóstico para Project Zomboid Build 42. Captura el estado del zombi antes de morir, lo compara con `OnZombieDead`, el `IsoDeadBody` definitivo y una línea temporal multietapa. También diferencia una pérdida aparente de un objeto que otro jugador haya movido. No repara ni modifica inventarios.

# SiK Corpse Loot Guard

Mod diagnóstico para Project Zomboid Build 42. Captura el estado del zombi antes de morir, lo compara con `OnZombieDead`, el `IsoDeadBody` definitivo y una recomprobación tardía. No repara ni modifica inventarios.

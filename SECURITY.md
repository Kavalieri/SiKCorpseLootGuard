# Security policy

Do not disclose credentials, multiplayer authority bypasses or exploitable
details in a public issue. Use GitHub's private vulnerability-reporting form:
https://github.com/Kavalieri/SiKCorpseLootGuard/security/advisories/new

Include the affected version, environment, impact, minimum reproduction and a
safe way to contact you. Do not publish an exploit before SiK confirms a fix.
Ordinary crashes and gameplay defects belong in the public issue tracker.
